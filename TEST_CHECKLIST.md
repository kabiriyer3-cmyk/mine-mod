# Игровая проверка

Все пункты пока **не проверены в игре**.

- [ ] GitHub Actions: validation, compile, tests и remap проходят.
- [ ] Клиент 1.21.1 + Fabric + Fabric API загружает мод без ошибок.
- [ ] Dedicated server запускается без загрузки клиентских классов.
- [ ] Контейнер ставится на 3 x 3, не ставится в блоках/на неровном полу.
- [ ] Ракета расходуется при загрузке в survival, не расходуется в creative.
- [ ] Пустая рука выдаёт пульт; отдельный пульт привязывается к выбранному контейнеру.
- [ ] Чужой игрок не может взять управление при ownerLock.
- [ ] Подходящая цель даёт зелёную метку и пуск после удержания, не сразу при касании кнопки.
- [ ] Препятствие над контейнером блокирует запуск.
- [ ] Крышка и ракета выходят без торчащих до пуска частей.
- [ ] Ракета летит быстро, низко; не отделяет ступени.
- [ ] Удержание позволяет менять метку; отпускание сохраняет последнюю.
- [ ] После завершения выстрела пульт показывает завершение, а не новый пуск.
- [ ] Стены и сущности между стартом и целью вызывают попадание, а не пролёт насквозь.
- [ ] Цель в незагруженном чанке/другом измерении не принимается.
- [ ] Взрыв короткий и обычный: нет гриба, экранного ослепления или огромного кольца.
- [ ] Кратер небольшой; контейнеры удаляются без россыпи предметов.
- [ ] Bedrock и служебные блоки сохраняются.
- [ ] Повторная зарядка и пуск не дублируют ракеты.
- [ ] Два клиента видят один и тот же запуск и попадание.
- [ ] Перезапуск во время полёта/работы кратера восстанавливает состояние.
- [ ] enableDestruction=false даёт попадание без изменений блоков и урона этой системы.
- [ ] Переход между мирами/измерениями очищает эффекты и звук.
- [ ] Упаковка контейнера не дублирует загруженный боезапас.
- [ ] После чистого прогона отдельно проверить Sodium/Iris и конкретный шейдерпак.

Для ошибки приложить: версию JAR, свежий `logs/latest.log`, список модов, GPU, настройки `solo-silo.json`, действие, ожидаемый/фактический результат. Для ошибки сборки нужен лог упавшего шага Actions.
