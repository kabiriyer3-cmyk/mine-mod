# План реализации, версия 8

## Согласованный результат

Полный ZIP исходного проекта Fabric 1.21.1 для самостоятельной загрузки пользователем в GitHub. GitHub Actions собирает JAR. Публикация, push, создание репозитория и установка на компьютер пользователя не выполняются.

Комплекс: стационарно устанавливаемая колёсная пусковая, без езды. Собственные модели, HD-текстуры, звук и визуальные эффекты. Учебная нагрузка и разрушение блоков. После обсуждения ограничений выбрана **игровая постановочная физика**, не инженерная модель реальной ракеты.

## Архитектура

- Общий модуль: регистрация, предметы, блоки, настройка, серверная сущность.
- Сеть: ограниченные пакеты управления и серверные сообщения состояния.
- Пуск: проверка владельца, дистанции, пространства, лимитов, координат и одноразового подтверждения.
- Полёт: чистый Java `FlightPath`, детерминированные игровые фазы и координаты. Сервер отсчитывает длительность, клиент строит изображение.
- Разрушение: `CraterJob`, отсортированные по радиусу колонки, лимиты по изменениям, проверкам и времени, ограниченная группа chunk tickets.
- Сохранение: очередь полётов и работ в JSON, запись через временный файл и предыдущая копия.
- Клиент: собственные TMSH-меши, анимация частей, billboard VFX, процедурные звуки и пульт.
- Единственный клиентский mixin: изменение ориентации камеры после её обновления. Прицел и положение игрока не меняются.

## Границы проверки

Нет подключения к компьютеру пользователя, установленного Minecraft, его GPU и логов. В рабочей среде Java 17, без интернет-доступа из командной оболочки. Поэтому локально выполнены независимые Java-тесты, проверки ресурсов, проверка синтаксиса/типов на тестовых API и программный preview ассетов.

Настоящая сборка JDK 21 + Minecraft + Fabric, загрузка мода и игровой прогон остаются отдельными этапами. Они не отмечены пройденными.

## Критерии приёмки

1. GitHub Actions выдаёт зелёную сборку и JAR.
2. Клиент и dedicated server загружаются без ошибок.
3. Пусковая ставится, сохраняется, заряжается, разворачивается и сворачивается.
4. На обоих клиентах совпадают запуск, разделение и попадание.
5. Учебный выстрел не меняет блоки.
6. Разрушительный выстрел создаёт кратер и удаляет содержимое контейнеров без потока лута.
7. Перезапуск сохраняет полёт и незавершённый кратер.
8. Отключённые вспышка и тряска действительно не отображаются.
9. После выхода из мира не остаются старые звуки и эффекты.
