# Solo Silo, новый объём

Цель: мод Minecraft Fabric 1.21.1 с маленьким одиночным контейнером, ручной меткой цели, быстрой одноступенчатой игровой ракетой и обычным разрушительным попаданием.

Сохранены: собственные HD-материалы, дым/огонь/звук, серверная авторитетность, лимиты нагрузки, ZIP для самостоятельного GitHub Actions.

Заменены: TEL-машина, координатный экран, длинная космическая траектория, ступени, ядерная стилистика. Полёт и наведение являются игровыми, не инженерной моделью реального вооружения.

Результат принимается последовательно:
1. Статические проверки и математические тесты.
2. Настоящая сборка Minecraft/Fabric в Actions.
3. Загрузка клиента и сервера.
4. Игровая проверка метки, запуска, попадания и повторной зарядки.
5. Проверка двух клиентов, сохранения, производительности и совместимости.

В текущем окружении доступен только первый этап. Остальные не считаются пройденными.
