# MODLOG

## 0.2.0-rc1, 2026-10-24

### Основа и сохранность

- Minecraft 1.21.1, Fabric Loader 0.16.14, Fabric API 0.116.4+1.21.1, Yarn build.3.
- CI: Temurin 21, Gradle 8.14.3, Loom 1.11-SNAPSHOT, прежний рабочий инструментарий альфы.
- Новый исходный проект подготовлен отдельно. Ранее выданный alpha-проект не перезаписывался.
- Компьютер пользователя, игра, профили, сохранения и репозитории не изменялись. Push, PR и установка не выполнялись.
- Экспериментальная физика альфы заменена на отдельную игровую траекторию в согласованном игровом варианте.

### Реализовано

- Регистрация предметов, сущности, блоков и 17 собственных звуков.
- Состояния STOWED / DEPLOYING / READY / LAUNCHING / EMPTY / STOWING, сохранение NBT.
- Владение, проверка площадки, зарядка, упаковка без дублирования боезапаса.
- Координаты и режим нагрузки, подтверждение пуска одноразовым серверным токеном.
- Синхронизация наблюдателей, игровые фазы полёта, лимиты очередей.
- Возобновляемые кратеры, чаша и вал, внешняя зона разрушения, обработка контейнеров без лута.
- Файловое сохранение с предыдущей копией и атомарной заменой, если поддерживается.
- TMSH-ридер, LOD моделей и текстур, движение опор, стрелы, гидроцилиндров, крышки и ступеней.
- Собственный дым, пламя, пыль, обломки, плазменный след, облако, вспышка с учётом направления взгляда и преграды.
- Собственный звук с задержкой и дальностной громкостью; две петли рёва.
- Камерная тряска без изменения server-side aim.
- Масштабируемый пульт, русская/английская локализация, HUD.
- Генераторы, статический валидатор, CI и документация.

### Исправления при проверке

- Исправлена форма носового обтекателя в генераторе: раньше профиль шёл от острия к основанию.
- Стабилизаторы выделены в самостоятельные части, добавлена анимация раскрытия после выхода из контейнера.
- Исправлена нормаль лобового стекла.
- Убрано повторное создание NumPy-массивов на каждом полигоне при генерации иконок.
- Внесена поправка API: `BlockSoundGroup`, а не несуществующий `SoundGroup`.
- Разделены первичное получение событий и повторная синхронизация, чтобы не переигрывать старые взрывы.
- Устранена потеря первых пакетов при смене клиентского мира.
- Проверка владельца выполняется до ограничения частоты команд, чужой пакет не блокирует владельца.
- Зарезервирован общий лимит летящих и ожидающих разрушения объектов.
- При отключении разрушений сохранённые работы приостанавливаются, а новые попадания становятся учебными.
- Перед заменой блока удаляется его block entity, чтобы стандартные контейнеры не рассыпали содержимое.

### Выполненные проверки

- Семь независимых тестов игрового полёта и радиального порядка работы прошли локально.
- Все исходники Java прошли локальную компиляцию с частными тестовыми API. Тестовые API **не включены** в ZIP и не заменяют настоящие зависимости.
- Ресурсы: JSON, одинаковые языковые ключи, форматы PNG/Ogg/TMSH, индексы, конечность координат, UV, наличие entrypoints и mixin проверены.
- Программный textured preview пусковой в двух положениях создан и просмотрен. Он не подтверждает рендеринг в игре.
- В коде эффектов не найдены вызовы `ParticleTypes`, `spawnParticles`, `createExplosion`, `SoundEvents` или размещение `Blocks.FIRE`.

### Не выполнено

- Gradle build нового RC на настоящем Minecraft/Fabric classpath.
- Запуск клиента или dedicated server.
- Проверка визуальной синхронизации, FPS, TPS, сохранения в настоящем мире и совместимости с шейдерами.

Причина: в рабочей оболочке нет интернет-доступа и установленной игры, подключение к компьютеру пользователя отсутствует.

### Следующий шаг

Загрузить этот полный проект в чистый репозиторий, дождаться GitHub Actions, затем пройти `docs/TEST_CHECKLIST.md` в копии Superflat-мира. Для диагностики использовать свежий `logs/latest.log` клиента и сервера и лог упавшего шага Actions.
