# Ручная приёмка

Статус всех пунктов ниже: **не выполнено в Minecraft**. Сохраняй дату, версию JAR, свежие логи и фактический результат.

## Подготовка

- [ ] Сделать полную копию тестового мира при выключенной игре.
- [ ] Создать отдельный Fabric 1.21.1 профиль с Fabric API и новым JAR.
- [ ] Первый прогон без Sodium/Iris и шейдеров, графика Fancy или Fast.
- [ ] Проверить `logs/latest.log`: нет missing textures/sounds, ошибок регистрации или mixin.
- [ ] Открыть Superflat, очистить площадку 27 x 5 с запасом пространства сверху.

## Пусковая

- [ ] Получить `topol:launcher` и `topol:missile`.
- [ ] Поставить пусковую в каждом из четырёх направлений.
- [ ] Убедиться, что курсор попадает в корпус, пульт открывается, вращение модели соответствует размещению.
- [ ] Проверить запрет установки на неровную/занятую площадку.
- [ ] Зарядить ровно один предмет; в survival он расходуется, в creative нет.
- [ ] Развернуть: опоры вниз, контейнер вверх, гидроцилиндры соединяют точки крепления, маяки и звук работают.
- [ ] Проверить запрет развёртывания при потолке.
- [ ] Свернуть: движения и состояние идут обратно.
- [ ] Упаковать приседанием + ударом: без дублирования предметов.
- [ ] Сохранить/загрузить развёрнутую и свёрнутую пусковые.

## Пульт и права

- [ ] Проверить русский и английский интерфейсы.
- [ ] Проверить UI scale на маленьком и большом окне, мышь и клавиатуру.
- [ ] Ввести пустые, отрицательные, недопустимые и слишком далёкие координаты.
- [ ] После подготовки изменить/отменить цель, проверить аннулирование подтверждения.
- [ ] Дождаться истечения 5 секунд, проверить отказ по старому подтверждению.
- [ ] Другой обычный игрок не может управлять чужой пусковой; оператор может.
- [ ] Проверить лимит нескольких активных полётов.

## Учебный полёт

- [ ] Выбрать учебный режим и цель на расстоянии 1000-2000 блоков.
- [ ] Подтвердить пуск: сирена, сброс крышки, холодный выброс, отрыв поддона, пауза до зажигания.
- [ ] Проверить раскрытие стабилизаторов и отсутствие деталей, торчащих сквозь контейнер.
- [ ] Проверить отделение первой, второй и третьей ступеней.
- [ ] У цели наблюдать снижение, собственный след, задержанный звук и пыль.
- [ ] Убедиться, что учебный выстрел **не изменил блоки и не нанёс взрывной урон**.
- [ ] Сохранить игру во время полёта, перезапустить, проверить его продолжение.
- [ ] Свернуть и зарядить пустую пусковую, повторить.

## Разрушительный выстрел

- [ ] Использовать только копию мира; поставить у цели контрольные блоки, сундук и устойчивый внешний материал.
- [ ] Подтвердить пуск в разрушительном режиме.
- [ ] Проверить вспышку снаружи и за стеной; проверить настройку её полного отключения.
- [ ] Проверить, что тряска не меняет направление прицела после эффекта.
- [ ] Проверить образование чаши, вала, спёкшегося и выжженного грунта.
- [ ] Убедиться, что сундук удалён без разброса инвентаря.
- [ ] Проверить урон и очистку не-живых объектов по расширяющемуся фронту.
- [ ] Убедиться, что bedrock и служебные блоки сохранены при настройках по умолчанию.
- [ ] Проследить, что визуальный фронт не обгоняет уже обработанную область.
- [ ] Перезапустить сервер во время обработки кратера: работа продолжается.
- [ ] Установить `enableDestruction: false`, перезапустить: сохранённая работа стоит на паузе.
- [ ] Проверить поведение воды/песка и внешних блоков; записать фактические ограничения.

## Два клиента и нагрузка

- [ ] Dedicated server загружается без попыток загрузить клиентские классы.
- [ ] Один клиент остаётся у пусковой, второй у цели; события соответствуют одному выстрелу.
- [ ] Присоединиться во время полёта и во время обработки кратера.
- [ ] Сменить измерение и вернуться: старые эффекты не дублируются.
- [ ] Выйти из мира: циклический рёв и гидравлика прекращаются.
- [ ] Запустить два выстрела, записать FPS/TPS, память, длительность обработки и загрузку диска.
- [ ] Проверить настройки пониженной плотности.
- [ ] Только после базового прогона добавить Sodium, затем Iris и конкретный шейдерпак по одному.
- [ ] Проверить F3+T, обычную и Fabulous-графику отдельно.

## Минимальный отчёт об ошибке

Версия Minecraft/Fabric/Fabric API/JAR, список модов, GPU, режим графики, настройки `topol.json`, точные действия, ожидаемый и полученный результат. Приложить свежие `logs/latest.log`, crash-report при наличии и лог сборки Actions, если упал Gradle.
