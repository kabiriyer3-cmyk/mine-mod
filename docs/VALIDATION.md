# Статус проверки 0.2.0-rc1

## Пройдено локально

- **7 тестов**: конечные точки, конечность значений и монотонность, повторяемость, непрерывность холодного старта, фазы ступеней, покрытие/порядок колонок кратера, форма чаши и повторяемость шума.
- Компиляция Java-синтаксиса и типов против специально подготовленных минимальных тестовых API: без ошибок. Эти API не являются Minecraft/Fabric и не входят в архив.
- Статическая проверка **20 JSON-файлов**, **72 совпадающих ключей локализации**, **17 монофонических звуков Ogg Vorbis 44.1 kHz**.
- Шесть TMSH-мешей: два уровня детализации для пусковой, ракеты и конечного аппарата. Проверены числа элементов, границы индексов, UV, отсутствие NaN/Infinity и лишних байтов.
- Высокая детализация пусковой: 11 869 четырёхугольников; низкая: 6 555. Высокая ракеты: 2 417; низкая: 1 136.
- Атласы модели: 2048/1024/512. Атласы дыма и пламени: 2048. Собственный textured software preview просмотрен.
- Пути стандартных эффектов, запрещённые в этом проекте, не найдены валидатором.

Независимые Java-тесты запускались с Java 17 и минимальным локальным тестовым раннером. В CI те же тесты запускает настоящий JUnit 5 на Java 21.

## Ещё не подтверждено

- Компиляция и remap JAR нового RC с настоящими Minecraft/Fabric/Yarn.
- Корректность mixin после remap.
- Загрузка клиента и dedicated server.
- Реальный вид VFX, освещение, прозрачность, модель в игре и звук.
- Сохранение/восстановление в Minecraft, networking с двумя клиентами.
- Производительность и совместимость с Sodium, Iris, Fabulous, шейдерпаками и другими модами.

**Ранее собранная альфа не является доказательством сборки этого RC.**

## Воспроизведение

```sh
python3 tools/validate_assets.py
gradle build --no-daemon --stacktrace
```

Первая команда требует только стандартную библиотеку Python 3. Вторая требует JDK 21, Gradle 8.14.3 и доступ к репозиториям зависимостей. В GitHub Actions всё это настроено.

Тесты в игре отмечаются только после выполнения соответствующего шага из `TEST_CHECKLIST.md`. Ни один шаг там заранее не отмечен.
